# Homebrew tap for Clipy

[Clipy](https://github.com/Gokulakrishnxn/Clipy) is a native macOS menu-bar clipboard manager with Text / Images / Links tabs and offline smart actions.

```sh
brew install --cask gokulakrishnxn/clipy/clipy
```

Always use the full name: Homebrew's own catalog has an unrelated cask called `clipy`.

- Update: `brew upgrade --cask gokulakrishnxn/clipy/clipy`
- Remove (with history): `brew uninstall --zap --cask gokulakrishnxn/clipy/clipy`

`Casks/clipy.rb` is updated automatically by the release workflow in the Clipy repo.
